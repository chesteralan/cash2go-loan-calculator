# Taste Profile

## Tooling
- Prefers bun as the package manager and script runner (e.g., "use bun" for CI/CD workflows — setup with `oven-sh/setup-bun`, `bun install --frozen-lockfile`, `bun run`/`bunx` instead of npm/npx). Confidence: 0.85

## Workflow
- Prefers planning each iteration before implementing, and doing that work on a fresh dedicated branch ("let's plan the next iteration on a new branch"); chose `feat/<topic>` naming for per-iteration branches (e.g., `feat/iteration-tests-pwa-calc`) over version-style names. Confidence: 0.6
